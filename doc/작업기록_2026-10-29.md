## 백엔드

### 1. 분석과 저장 분리
- `POST /articles/analyze`(저장 안 함) / `POST /articles`(승인한 태그만, 한 트랜잭션)
- 저장 요청은 서버가 다시 검증 (URL 형식, 길이, 태그 1~10개, 태그 ID 소유권, 중복)
- 크롤러: `og:site_name` → publisher, 발행일 없으면 null
- 서버 테스트 도입: `node:test`, 크롤러·Claude는 가짜로 바꾸고 개발 DB에 임시 사용자를 만들었다 지움

### 2. 기존 태그 ID 재사용
- 기존 태그를 `T1`, `T2` 번호로 Claude에 넘기고 서버가 실제 ID로 바꿈 (Claude가 ID를 지어내지 못하게)
- 새 태그에는 비슷한 기존 태그(`similarExisting`)를 함께 돌려줌
- 응답 형식: 정규식 JSON 추출 → 구조화 출력(JSON 스키마)
- 정한 것: `Tag.category` 고정 목록(사회학, 철학, 정치학, 경제학, 심리학, 인류학, 커뮤니케이션학, 기타),
  `Article.summary`를 Claude 요약으로

### 3. 책 스크랩
- **OCR 서비스: Google Cloud Vision** (`DOCUMENT_TEXT_DETECTION`) 선정. 키 발급·결제 연결은 사용자가 진행
- `POST /book-scraps/analyze`(multipart 사진) / `POST /book-scraps`, 목록·상세·삭제
- 근거 문장은 공백을 빼고 OCR 텍스트와 글자 단위로 대조, 다르면 버리지 않고 `excerptVerified: false`("확인 필요")
- 사진은 메모리에서만 처리, 형식·해상도(긴 변 1000px 이상)는 파일 바이트로 확인
- 정한 것: 책 스크랩 제목 필드는 만들지 않고 **요약을 제목 자리에** 쓴다
- 실측에서 발견한 것
  - 샘플 사진이 확장자만 `.jpg`인 WebP → WebP 지원 추가
  - Claude가 떨어진 문장을 이어 붙여 검증 실패 → 근거 문장을 **연속 구간 배열(excerpts)** 로 받고 구간마다 검증, ` … `로 이어 저장
  - 태그 이름이 설명문으로 나옴 → "짧은 개념어" 규칙과 예시 추가
  - 오버레이에 가려진 본문을 Claude가 지어냄 → 검증이 "확인 필요"로 잡음 (의도대로)

### 3+. 분석 비용·품질 기록
- 분석마다 비용·자동 지표·Claude 채점을 `server/logs/analysis-YYYY-MM.jsonl`에 기록, `npm run eval:report`로 요약
- 채점 기준표 `server/src/eval/rubric.md` (채점 프롬프트에 그대로 들어감)
- 채점 모델을 Haiku 5.5 + 기준표 프롬프트 캐시로 바꿔 채점 14원 → 약 1.5원
  (Haiku 4.5는 4,096토큰 미만을 캐시하지 않음)
- `ANALYSIS_JUDGE_UNTIL=YYYY-MM-DD`로 실측 기간에만 채점

### 4. 관계 제안·마인드맵·관리 API
- 정한 것: 백그라운드는 **우선 서버 프로세스 안에서** (작업 큐로 바뀔 수 있음), 제안은 **2단계 방식**,
  **연결 끊기도 REJECTED로 보존**
- 관계 제안: 이름만 보고 후보 8쌍 → 스크랩 요약·이유·근거 문장으로 근거 확인 → 서버 검증 후 최대 3개 SUGGESTED
- API: `/concepts`(목록, `/graph`, `?center=`, `/graph/preview`, 상세·설명 수정·삭제·병합), `/relations`(목록·상세·상태/이유 수정)
- 스크랩 삭제 시 근거가 사라진 관계(거절 제외) 정리
- 실측: 판옵티콘(책)—감시사회(기사), 감시사회—소외(같은 기사) 제안, 저장 1건당 약 8원
- 발견: Claude가 번호 대신 이름("감시사회 ★", 오타 "판옥티콘")으로 답함 → **번호 필드를 스키마 enum으로 묶음**
  (태그 재사용 `existingTag`에도 같은 위험이 있어 함께 적용)

### 9. 보안 보완
- 정한 것: Refresh 토큰은 **테이블 추가** (테이블 9개), 분석 호출 **사용자별 시간당 20회·하루 60회**
- Access 15분 + Refresh 30일, 갱신 때마다 교체, 재사용 감지 시 그 로그인의 토큰 모두 폐기, `/auth/refresh`·`/auth/logout`
- 로그인 IP별 실패 10회/15분, helmet, `CORS_ORIGINS`, JSON 100kb, 500 오류 메시지 숨김, 회원가입 입력 검증
- 만들다 잡은 버그: 재사용 감지 후 폐기가 트랜잭션 롤백으로 되돌려짐 → 트랜잭션 밖으로
