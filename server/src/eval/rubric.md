# 분석 결과 채점 기준표

기사·책 분석(`POST /articles/analyze`, `POST /book-scraps/analyze`)이 끝날 때마다
채점용 Claude가 이 문서를 그대로 읽고 항목별로 1~5점을 매긴다.
**이 문서를 고치면 채점 기준이 바로 바뀐다** (`server/src/eval/rubric.md`).
기록은 `server/logs/analysis-YYYY-MM.jsonl`, 요약은 `npm run eval:report`.

## 채점 원칙

- 각 항목은 1~5점 정수. 아래 구간 설명 중 결과에 가장 가까운 것을 고른다.
- 두 구간 사이면 낮은 쪽을 준다 (후하게 주지 않는다).
- 판단 근거는 원문(기사 본문 또는 OCR 텍스트)에서만 찾는다. 채점자의 배경지식으로 원문에 없는 내용을 채워 넣지 않는다.
- 해당 없는 항목은 null (예: 기존 태그가 하나도 없으면 "기존 태그 재사용"은 null).
  채점자가 점수를 줘도 서버가 null로 바꾼다 (기존 태그 없음 → `reuse`, 기사 → `excerpt_choice`).
- 근거 문장의 글자 일치 여부(`excerptVerified`)는 채점자에게 보여 주지 않는다. 내용만 보고 채점한다.

## 항목

### 1. 개념 적합성 (`concept_fit`)
태그가 실제 학문 개념이고, 이 원문에 정말 해당하는가.

| 점수 | 기준 |
|---|---|
| 5 | 모든 태그가 학계에서 쓰는 개념이고, 원문의 핵심 현상·주장을 정확히 가리킨다. 빠진 핵심 개념이 없다 |
| 4 | 모두 적절하지만 하나가 다소 주변적이거나, 더 정확한 개념이 있다 |
| 3 | 하나는 억지스럽거나 원문과 약하게만 이어진다. 또는 원문의 핵심 개념이 빠졌다 (원문이 학술 개념어를 직접 썼는데 태그에 없으면 여기에 해당) |
| 2 | 절반 이상이 억지스럽거나, 학문 개념이 아닌 일상 키워드다 |
| 1 | 태그가 원문과 거의 무관하거나 태그가 없다 (원문에 분명한 사회 현상이 있는데도) |

### 2. 태그 이름 (`tag_naming`)
다른 스크랩에도 붙일 수 있는 짧은 개념어인가.

| 점수 | 기준 |
|---|---|
| 5 | 모두 통용되는 개념어, 짧은 명사구 (예: 아노미, 지위 불안, 낙인 효과) |
| 4 | 대체로 개념어지만 하나가 덜 통용되는 표현이거나 약간 길다 |
| 3 | 하나가 원문 내용을 풀어 쓴 구절이거나, 두 개념을 묶거나 새로 조합한 이름이다 (예: "청년층의 고용 불안 심화", "불안과 지위 경쟁", "염세주의적 거리두기"). 통용되는 학술 용어(지위 불안, 염세주의)가 있는데 쓰지 않은 경우 |
| 2 | 절반 이상이 풀어 쓴 구절이다 |
| 1 | 모두 문장형·설명형이라 다른 스크랩과 연결될 수 없다 |

### 3. 근거·풀이의 충실성 (`grounding`)
reason·explanation·description이 원문에 근거하고, 지어낸 사실이 없는가.

| 점수 | 기준 |
|---|---|
| 5 | 풀이가 원문의 구체적 사건·인물·문장을 짚고, 지어낸 사실·학자·연도가 없다 |
| 4 | 근거는 맞지만 일부가 일반론에 머문다 |
| 3 | 원문과 맞지 않는 해석이 하나 있거나, 대부분 일반론이다 |
| 2 | 원문에 없는 사실을 단정하거나, 확인되지 않은 학자·연도를 쓴다 |
| 1 | 풀이가 원문과 다르거나 지어낸 내용이 중심이다 |

### 4. 요약 (`summary`)
요약만 보고 다른 스크랩과의 개념 연결을 판단할 수 있는가 (관계 제안 입력으로 쓴다).

| 점수 | 기준 |
|---|---|
| 5 | 2~3문장으로 핵심 사실·주장(누가·무엇을·왜)을 정확히 담았다 |
| 4 | 정확하지만 중요한 요소 하나가 빠졌다 |
| 3 | 대체로 맞지만 모호하거나 지엽적인 내용에 치우쳤다 |
| 2 | 원문과 어긋나는 내용이 있다 |
| 1 | 원문을 잘못 요약했거나 비어 있다 |

### 5. 기존 태그 재사용 판단 (`reuse`)
기존 태그 목록과 같은 개념이면 재사용하고, 다른 개념이면 새로 만들었는가. 기존 태그가 없으면 null.

| 점수 | 기준 |
|---|---|
| 5 | 재사용·새 태그 판단이 모두 맞다 |
| 4 | 재사용할 만한 기존 태그를 하나 놓쳤지만 새 이름이 그 태그와 쉽게 연결된다 (비슷한 태그로 제시됨) |
| 3 | 같은 개념의 기존 태그를 놓치고 새 태그를 만들었다 |
| 2 | 다른 개념인데 기존 태그로 잘못 연결했다. 또는 원문의 핵심이 아닌 기존 태그를 넣느라 원문의 핵심 개념이 빠졌다 |
| 1 | 재사용 판단이 여러 개 틀렸다 |

### 6. 근거 문장 선택 (`excerpt_choice`) — 책만
태그마다 고른 근거 문장이 그 개념을 가장 잘 보여 주는 본문인가. (글자 일치는 서버가 따로 검사하므로 여기서는 내용만 본다.) 기사는 null.

| 점수 | 기준 |
|---|---|
| 5 | 모든 근거 문장이 해당 개념이 드러나는 핵심 문장이고, 태그마다 다른 부분이다 |
| 4 | 적절하지만 하나가 더 좋은 문장을 두고 덜 핵심적인 문장을 골랐다 |
| 3 | 하나가 개념과 약하게만 이어지거나, 태그 간 근거가 겹친다 |
| 2 | 근거 문장이 대부분 개념과 무관하거나 본문이 아닌 글자(머리말·앱 표시)를 담았다 |
| 1 | 근거 문장이 없거나 원문에 없는 문장이다 |

## 종합 점수와 등급

종합 점수 = null을 뺀 항목 점수의 평균 (소수 첫째 자리). 등급은 서버가 계산한다.

| 종합 점수 | 등급 |
|---|---|
| 4.5 이상 | 우수 |
| 3.5 이상 | 양호 |
| 2.5 이상 | 보통 |
| 1.5 이상 | 미흡 |
| 1.5 미만 | 부적합 |

## 자동 지표 (채점자와 별개로 서버가 계산)

| 지표 | 뜻 |
|---|---|
| `tagCount` / `newTags` / `reusedTags` | 제안 태그 수, 그중 새 태그·재사용 태그 수 |
| `nameMatched` | 새 이름이라 했지만 기존 태그와 글자가 같아 서버가 보정한 수 (재사용 실패 신호) |
| `excerptVerifiedRate` | 책: 근거 문장이 OCR 텍스트와 글자 그대로 일치한 비율 |
| `avgTagNameLength` | 태그 이름 평균 글자 수 (길면 풀어 쓴 이름일 가능성) |
